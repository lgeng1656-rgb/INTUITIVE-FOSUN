# 医疗互动三层导航更新设计

## 目标

使用 GG 提供的 2026-07-29 新版图片更新首页，并将术前、术中、术后改为“首页 → 阶段放大页 → 文字与视频页”的三层导航。保留首页环形动画、16:9 固定舞台和现有腾讯 COS 视频配置。

## 页面与交互

- 首页使用新版蓝紫背景、中间三阶段画面、底部产品图和两侧入口。
- 点击每个阶段画面的左半边、右半边、阶段标题或其下方两个功能文字，均进入该阶段放大页。
- 阶段放大页分别使用 `术前亮.jpg`、`术中亮.jpg`、`术后亮.jpg`；屏幕和白板已有静态亮光，并叠加醒目的周期性呼吸效果。
- 阶段放大页左半边和右半边分别进入对应的文字与视频页；右上角原图返回按钮直接回首页。
- 文字与视频页使用 `前技能.jpg`、`前规划.jpg`、`中决策.jpg`、`中远程.jpg`、`后复盘.jpg`、`后质控.jpg` 作为整页背景，右侧嵌入对应视频。点击视频外任意位置返回阶段放大页。
- 左侧“临床应用功能整合”进入 `左icon.jpg` 文字与视频页，右侧嵌入原机器人功能整合视频；点击视频外任意位置返回首页。
- 其他原有视频页继续点击任意位置返回上级页面。
- 首页环形箭头动画保持原实现和运动轨迹不变。

## 实现边界

- 保持 React、Vite、现有导航状态机和数据驱动热点结构。
- 不引入新框架，不删除旧素材，不修改 Cloudflare 或密钥配置。
- 新素材复制到 `public/assets/medical/`，源文件保持不动。
- 通过数据配置定义页面、视频与热区；通过 CSS 实现呼吸效果。
- 保留工作区现有未提交改动，并在其基础上增量实现。

## 验收

- 首页三阶段任一规定入口均进入正确阶段放大页。
- 三个阶段放大页左右半边进入正确三级页，返回按钮回首页。
- 七个文字与视频页均显示完整背景、右侧视频并按确认规则返回。
- 环形动画继续运行，呼吸效果醒目但不遮挡原画面。
- `npm.cmd test` 与 `npm.cmd run build` 通过，并完成本地浏览器点击验证。
